Membership filter playground

Type a name. Add it, then Check names. A filter answers only “definitely NOT” or “maybe”.

32 bits, 3 hash functions. Every name lights up 3 bits.
8 buckets × 2 slots. Each name stores a small fingerprint, and has exactly 2 buckets it may live in.
